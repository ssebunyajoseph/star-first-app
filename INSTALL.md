# Install Star first App

**Star first App** is a Progressive Web App (PWA) that works on all devices and can be installed like a native app. It works completely offline and stores all your tasks locally.

## Quick Install (Recommended)

### Desktop (Chrome, Edge, Firefox, Safari)
1. Open the app: [https://ssebunyajoseph.github.io/star-first-app/](https://ssebunyajoseph.github.io/star-first-app/)
2. Look for the **"⬇️ Install"** button in the top-right corner
3. Click it and confirm the installation
4. The app will open as a standalone window on your desktop
5. It's now installed! You can launch it from your apps menu or home screen

**Alternative method (if no install button appears):**
- **Chrome/Edge:** Click the address bar menu (⋮) → "Install app" or use the install icon
- **Firefox:** Click the home icon in the address bar → "Install"
- **Safari:** Share menu → "Add to Home Screen"

### Mobile (iPhone/iPad)
1. Open Safari and go to: [https://ssebunyajoseph.github.io/star-first-app/](https://ssebunyajoseph.github.io/star-first-app/)
2. Tap the **Share** button (arrow pointing up)
3. Scroll down and tap **"Add to Home Screen"**
4. Name it "Star first App" and tap **Add**
5. The app icon will appear on your home screen!

### Mobile (Android)
1. Open Chrome and go to: [https://ssebunyajoseph.github.io/star-first-app/](https://ssebunyajoseph.github.io/star-first-app/)
2. Tap the menu button (⋮) in the top-right
3. Tap **"Install app"** or **"Add to Home Screen"**
4. Follow the prompts to confirm
5. The app is now installed on your device!

## Features When Installed

✅ **Works Offline** - Full functionality without internet connection  
✅ **Instant Launch** - Opens instantly like a native app  
✅ **No Browser UI** - Runs in standalone mode  
✅ **Home Screen Icon** - Easy access from your home screen or app drawer  
✅ **Fast Performance** - Cached for ultra-fast loading  
✅ **Local Storage** - All tasks stored on your device, never synced to servers  
✅ **Light & Dark Modes** - Built-in theme support  
✅ **Accessible** - WCAG compliant with full keyboard support  

## What Happens Offline?

Once installed, Star first App will:
- ✅ Load instantly
- ✅ Create new tasks
- ✅ Mark tasks complete
- ✅ Delete tasks
- ✅ Change themes
- ✅ Save all changes locally

**Note:** When you come back online, your app data remains on your device (no cloud sync).

## Storage & Privacy

- **All data is stored locally** on your device
- **Zero tracking** - no analytics or telemetry
- **No account required** - works completely anonymously
- **No data sent to servers** - just the app code
- **You control your data** - clear app data anytime from settings

### Desktop
- **Windows/Linux:** Right-click the app → Uninstall
- **Mac:** Drag the app to Trash

### Mobile
- **iPhone/iPad:** Long-press the icon → Remove App
- **Android:** Long-press the icon → Uninstall

## Troubleshooting

### Install button not showing?
- Make sure you're on the latest browser version
- Try a different browser (Chrome recommended)
- PWA features require HTTPS (which we have)

### App not loading offline?
- The app must be installed first (not just visited)
- Check that you have at least 5MB of storage space
- Clear browser cache if issues persist

### Tasks not syncing across devices?
- Tasks are stored locally by design (no cloud sync)
- To transfer tasks, export them and reimport on another device
